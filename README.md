# Freaky Fashion

A fashion e-commerce web app built as a school project at EC Utbildning. It includes a storefront and an admin area for managing products and categories.

> Educational project, not production-ready. The session secret is hardcoded and dependencies are older versions.

## Features
Product and category pages, search, favorites and a shopping basket
User registration and login (session-based)
Admin area (/admin) to add and delete products and categories, with image upload

## Tech stack

Node.js, Express, EJS, SQLite (better-sqlite3), express-session, multer, HTML, CSS, JavaScript

## Getting started

Requires Node.js 20 or later.

```bash
git clone https://github.com/AnderssonMy/freakyfashion.git
cd freakyfashion
npm install
npm run dev
```

Open http://localhost:3000. The admin area is at /admin/products.
